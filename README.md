# Student Performance Classification using Classical Machine Learning

A Python-based academic Machine Learning project that classifies students into three performance tiers:
- **High Performer**
- **Average Performer**
- **Needs Improvement**

## Getting Started

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run Training & Evaluation (Already Completed)
The model has already been trained and saved. To reproduce:
```bash
python scratch/phase3_training.py
```
This will:
- Fit Logistic Regression, Decision Tree, and Random Forest
- Output `outputs/model_comparison_cv.csv`
- Save figures to `outputs/figures/`
- Save the winning pipeline to `models/best_student_model.joblib`

### 3. Verify the Inference Module
```bash
python src/verify_inference.py
```
Runs 21 verification tests to confirm model loading, prediction, validation, and consistency.

## Running the Student Performance AI UI

### Step 1: Install Requirements
```bash
pip install -r requirements.txt
```

### Step 2: Launch the Application
```bash
streamlit run app.py
```

### Step 3: Use the Application
1. The application opens in your web browser.
2. Enter the four academic values:
   - **MST Score** (0–100)
   - **Quiz Score** (0–100)
   - **Attendance %** (0–100)
   - **Assignment Score** (0–100)
3. Click **ANALYZE PERFORMANCE**.
4. View the predicted Performance Category and model probability distribution.
5. Click **Clear & Reset** to make another prediction.

### About the Prediction
- The prediction is generated by the trained Logistic Regression model.
- Probabilities represent the model's estimated class probabilities, not certainty guarantees.
- The model achieved **94.00% accuracy** and **91.18% Macro F1-Score** on the held-out test set.

## Academic ML Principles Followed
- **No Data Fabrication**: All predictions come from the trained model.
- **Zero Data Leakage**: StandardScaler and SimpleImputer are chained inside sklearn Pipeline objects fitted only on training data.
- **Explainable Models**: Classical classifiers with full evaluation metrics and interpretability analysis.
- **Target Leakage Prevention**: `Performance_Score` is excluded from features.
- **Class Imbalance Handling**: `class_weight='balanced'` without synthetic oversampling.
